# Attention Visualizer for Machine Translation

## Project Overview
This project is designed to visualize the Attention Mechanism used in Neural Machine Translation (NMT).

It helps users understand how an AI model focuses on different words while translating a sentence from one language to another.

## Technologies Used
- Python
- Machine Learning
- Neural Machine Translation
- Attention Mechanism

## Project Files
- `app.py` – Main application
- `model.py` – Model implementation
- `train.py` – Model training
- `analyze.py` – Analysis
- `data.py` – Data handling
- `compare.py` – Comparison
- `requirements.txt` – Required Python libraries
- `Dockerfile` – Project configuration

## Installation

1. Download or clone this repository.
2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Run the application using the appropriate project command.

## Conclusion
This project demonstrates the role of the Attention Mechanism in Neural Machine Translation through visualization.
